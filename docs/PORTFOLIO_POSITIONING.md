# Portfolio positioning

## Current strengths

- FastAPI backend with persistent learning progress
- structured 24-month curriculum and exam flows
- multi-tenant staff and cohort APIs
- review workflow for generated learning content
- Railway deployment and production health checks

## AI positioning

Present this repository as an AI-enabled product and backend engineering project with explicit review gates for generated content.

Do not present retrieval, embeddings or vector search as completed production capabilities yet. Those items remain future work in the current repository roadmap.

For stronger agentic AI and RAG examples, use the Maintenance AI Assistant and Booking Email Platform repositories.
